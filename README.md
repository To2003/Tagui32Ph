# Tagui32

Web de fotografía deportiva. La especificación completa está en
[`tagui32-especificacion.md`](./tagui32-especificacion.md).

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Base de datos

El esquema completo de Supabase está en [`supabase/schema.sql`](./supabase/schema.sql).
Pegarlo entero en el SQL Editor del proyecto de Supabase y ejecutarlo.

## Variables de entorno

Copiar `.env.example` a `.env.local` y completar (ver Fase 1 del chat para el detalle
de qué generar en cada servicio).
